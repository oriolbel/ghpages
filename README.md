# ghpages
Testing GH pages

A dummy FMCG coffee brand static site — Brewhaus Coffee Co.

## Pages

- [index.html](index.html) — homepage with hero banner and featured products
- [product.html](product.html) — product detail page for the Midnight Dark Roast
- [css/style.css](css/style.css) — shared coffee-brand styling

## Usage

Open [index.html](index.html) in a browser, or serve the folder locally, e.g.:

```sh
python3 -m http.server
```
